# 名刺管理（Webアプリ / PWA）

iPhone で名刺の表裏を撮影 → 端末内でOCR → 「所属・専門科・役職・姓・名」などに自動で振り分けて保存。
Mac と iPhone の両方で検索・閲覧でき、データは iCloud Drive 上の1ファイルで受け渡しします。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（**個人情報は含まない**。仕組みだけ） |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面アプリ化・オフライン動作用 |
| `vendor/tesseract/` | OCRエンジン（Tesseract.js v7・日本語/英語辞書）。CDNを使わず同梱 |

名刺データ・画像は **各端末の IndexedDB** と、自分で保存する **iCloud Drive の `名刺データ.meishi`** にだけ存在します。

## 設置（どちらか）

iPhone のカメラ・ホーム画面アプリ化には **HTTPS で配信**する必要があります。HTMLに個人情報が入っていないので、公開の静的ホスティングに置いても名刺データは外に出ません。

- **GitHub Pages（おすすめ・無料）**：このフォルダの中身をリポジトリに入れて Pages を有効化 → `https://<ユーザー名>.github.io/<リポジトリ名>/` で開く
- そのほか Netlify / Cloudflare Pages など任意の静的ホスティング

※ ローカルの `file://` で直接開くと OCR（Web Worker）が動きません。

## 使い方

### iPhone
1. Safari で URL を開き、共有 →「ホーム画面に追加」。以後は**ホーム画面のアイコンから**使う
   （Safariのタブとホーム画面アプリはデータが別々。タブ側は長期間使わないと消えることがある）
2. 「＋ 追加」→ 表面「📷 撮影」→ 裏面「📷 撮影」（裏面は任意）
3. 自動で読み取り・振り分け → 確認して「保存」
   - 振り分けが違うとき：入力欄をタップ →「読み取った文字」の行をタップすると、その欄に入る
   - 姓名の区切りが違うとき：「⇆ 区切り」
   - 精度が足りないとき：写真アプリで名刺の文字を長押し（テキスト認識表示）→ すべてコピー →「📋 テキストを貼り付けて振り分け」

### メモ
- 名刺の詳細画面の「📝 メモ」欄に書いて「追加」（Macは ⌘+Enter）。日付付きで追記されます。
- メモの内容も検索対象。一覧では一致したメモの該当部分が表示されます。まとめて直すときは「編集」から。

### CSVの書き出し・読み込み（☁︎ →「CSV」）
- 書き出し：全件または表示中（検索・絞り込み結果）の名刺を、Excelで文字化けしないCSV（UTF-8・BOM付き）で保存。画像は含みません。
- 読み込み：このアプリのCSVのほか、Eight・Sansan・Excelの表に対応。列名（氏名／姓・名、会社名、部署名、役職、TEL、e-mail、住所、備考 など）から自動で判別し、文字コード（UTF-8／Shift_JIS）も自動判別します。
- 同じ名刺の扱い：このアプリで書き出したCSVはIDで照合して更新（画像は保持、内容が同じ行は変更なし）。同じ名前・所属の名刺がある場合は「上書き更新／読み込まない／新規追加」を選べます。

### Mac
- Safari / Chrome で同じ URL を開く。画像はドラッグ＆ドロップでも追加可。`/` キーで検索へ。
- Chrome / Edge では保存先ファイルを一度選ぶと、以後はワンクリックでそのファイルに上書き保存・読み込みできます。

### Mac ⇄ iPhone の同期（iCloud Drive）
「☁︎」→ **読み込み（統合）→ 保存** の順で行います。
- 同じ名刺は更新日時が新しい方を採用。削除も相手側に反映されます。
- iPhone の保存：共有シート →「"ファイル"に保存」→ iCloud Drive の任意フォルダ →（2回目以降）「置き換える」
- 名刺の保存・メモ追加・削除のあとに画面下へ「iCloudに保存」バーが出ます。iPhoneでは保存ファイルを裏で準備済みなので、タップするとすぐ共有シートが開きます（→「"ファイル"に保存」）。上部のバナーには前回の保存からの日数も表示されます。
- 「パスワードで暗号化して保存」をオンにすると AES-256-GCM で暗号化。パスワードは各端末で最初の1回だけ入力し、以後は端末内に記憶した鍵（取り出し不可の形式。パスワード自体は保存しない）で自動的に暗号化・復号します。パスワードを忘れると他の端末で復元できません。

## プライバシー設計

- **外部送信なし**：OCRは端末内（WebAssembly）で実行。CSP（Content-Security-Policy）で、自サイト以外への通信・画像読み込みをブラウザレベルで禁止しています。
- 例外は、アプリ本体とOCRエンジンを自分の配信元から読み込む通信のみ（名刺データは送られません）。
- 名刺の削除時は内容を消し、同期用の「削除済み」印（ID と日時のみ）だけを残します。

## 既知の制限

- OCR精度は撮影条件に左右されます（真上から・明るく・名刺を画面いっぱいに）。毛筆体や装飾フォント、縦書き名刺は苦手です。保存前に確認・修正してください。
- iPhone の写真ライブラリの HEIC は Safari では読めますが、Mac の Chrome では読めません（Safari を使うか JPEG で）。
- 画像は保存時に縮小・圧縮（標準：長辺1400px・約120KB以下、対応ブラウザではWebP）。OCRは縮小前の画像で行うため精度は落ちません。設定（☁︎ →「画像の保存サイズ」）で小／標準／大を選べ、保存済みの画像もあとから縮小できます。圧縮はすべて端末内のcanvasで処理し、外部には送信しません。
